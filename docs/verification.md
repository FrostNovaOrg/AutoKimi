# 验证范围与限制

## 仓库抽取验证

基线：官方 Kimi Code 2.3.0，提交 `b5e28fd6beac752a2cdcc0ff2f5fdf40e6494fbb`。开发机为 macOS arm64。

从本地官方 Git 对象还原基线，忽略开发目录的未提交改动，重新应用仓库补丁和 overlay，再冻结安装依赖、构建所有所需内部包及 CLI。构建成功。

- 原生集成相关 13 个测试文件、332 项测试通过。
- 引擎、SDK、TUI TypeScript 检查通过。
- 引擎无注释检查通过，扫描 1780 个文件。
- 仓库工具的 13 项隔离测试通过，覆盖源码还原、缓存保护、依赖打包、配置保留、命令参数转发、重复安装、入口文件篡改和体积/敏感信息守卫。
- 实际运行包的安装、SDK 配置保留、启动和重复安装检查通过。验证使用临时配置与目录，不更新用户正在使用的运行时或登录配置。

最终测试数量和仓库体积以当前提交的 CI 或本地检查输出为准。未将整个上游所有检查都宣称为通过；该基线有与本项目无关的既存导入边界检查问题。

## 抽取前已完成的功能验证

当前二元审核实现曾在实际安装的原生 TUI 中验证：模拟通过后创建测试文件；两阶段不确定后拒绝和无效响应拒绝均不创建文件，也不显示权限人工批准框。

真实 Kimi 模型曾对 8 个选定用例进行审核：2 个普通操作通过、2 个危险操作拒绝、2 个无法验证的脚本拒绝、2 个预检规则直接拒绝。共 10 次模型请求，未出现请求错误。待审工具没有实际执行，因此这些模型分类用例不等同于危险操作端到端执行测试。

另有针对超时排查的 4 个合成用例，2 个通过、2 个拒绝，共 6 次模型请求，均在约 4.9–25.4 秒返回。样本很小且均低于原 30 秒，不能用于证明延长至 90 秒后的生产超时率改善。

此次整理不重复消耗用户模型额度。原始记录含本机路径和会话信息，未提交到本仓库。

## 已知限制

模型审核可能误拒绝、误放行，有限用例不代表覆盖真实任务的全部风险。审核器只处理原有权限系统交给它的待审批操作，并非所有工具调用。它既不是 OS 沙箱，也不能独立阻止已被上游权限规则直接允许的行为。

审核上下文经过选择，不含工具结果或脚本正文；更早的用户授权可能不在当前根代理上下文中。多阶段仍可能超时，且两阶段使用同一模型，不具有模型独立性。

安装器只校验运行时和 SDK 入口文件摘要，依赖完整性依靠冻结安装与可信来源；运行包未做加密签名。Linux 的完整 TUI、其他 Kimi 版本、所有 provider/模型组合尚未验证。官方升级须重新移植和测试。
